# UnstableKills

Клиентский мод для Fabric, который отслеживает **реальные** смерти игроков на любом сервере.

## Что делает
- Ловит сетевой пакет `EntityStatusS2CPacket` со статусом `3` (смерть сущности).
- Запоминает UUID умершего игрока на 5 секунд.
- Когда в чат приходит ванильное сообщение о смерти — проверяет, было ли реальное подтверждение.
- Если смерть **подтверждена** — выводит жёлтое `<имя> left the game`.
- Если смерть **фейковая** (сервер подделал сообщение) — выводит красное `[FAKE DEATH] <сообщение> (не подтверждено!)`.

## Требования
- Minecraft 1.20.1
- Fabric Loader 0.14.21+
- Fabric API
